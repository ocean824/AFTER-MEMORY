# AFTER//MEMORY

Atmospheric horror/action-adventure built around confronting colossal entities and collecting/restoring fragmented memories that alter the player's understanding of the world.

## Unreal foundation
Narrative Pro 2 + Ultra Game Template 1.3; Boss AI Toolkit/Boss Animations/BlackMoon Boss Bundle for colossal encounter prototyping; Bodycam/Black Eye/Post-Process components only where the desired horror camera language benefits; Interactive Story supplement; Time Travel System only if memory-state mechanics require temporal reconstruction rather than simple flashbacks.
